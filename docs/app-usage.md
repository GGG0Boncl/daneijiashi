# 大内家事 · 手机端使用说明

> 给家里人看的，不用看懂技术细节。

## 一、装到手机上（只做一次）

1. 把 `大内家事-1.1-debug.apk` 发到手机（微信/QQ 传文件、数据线拷都行）。
2. 点开这个文件，手机会提示「未知来源应用」——允许一次即可（这是自己装的 App，不走应用商店）。
3. 装好后桌面上会出现「大内家事」🐱。**覆盖安装会保留原来的记录**；只有卸载重装才会清空，清空前先在「朕的私事 → 复制全部数据」里备份。
4. 若桌面还显示旧图标：先重启手机 / 换一下桌面（launcher 有图标缓存）；仍旧的话，备份数据 → 卸载 → 装 `大内家事-1.1-debug.apk`。这一版 `versionCode=2`，装上后「朕的私事」底部会写「大内家事 v1.1」，可据此确认不是旧包。

## 二、第一次打开（只做一次）

1. 写一个称呼，比如「妈妈」——**每台手机写自己的**，数据是分开的。
   - 中文、英文、数字、空格、emoji 都可以（比如「瑞瑞🥚」），最多 32 个字符。
   - 只有这些符号不行：`/ \ : * ? " < > |`（会把文件路径弄坏），也不能是 `con`、`nul` 这类 Windows 保留名。
   - 同一台手机改称呼等于换了个人，以前的记录不会跟着走，所以起好就尽量别改。
2. 允许通知权限（不给的话就收不到 07:30 / 21:30 与差事到点的提醒；Android 13+ 会单独问一次）。
3. 回家连上家里的 WiFi 后，点最右「朕的私事」→「自动找中枢」→ 看到「找到中枢」就成了（点右上角驿牌也一样能找）。

## 三、每天怎么用

- 早上想好了目标，点输入框加进去，一天写 2~4 条最舒服。
- 做到了点左边的圆圈变成 ✓；确实没做到就点 ✗，可以顺手写一句为什么（写下来才知道卡在哪）。
- 21:30 之后想起来还没打卡，随时补，不影响记录。
- 底栏两页：**🏯 朝廷 / 📜 起居**，最右是 **🐱 朕的私事**（设置、成员、同步、提醒都在这里）。

## 四、看历史（行事历）

- 「起居 → 行事历」是一个**月历**：哪天空着、哪天做了一半、哪天全做完，颜色一眼能看出来。
  - 浅灰＝没记录，粉＝一条没成，米黄＝做了一部分，浅绿＝全完成
  - 今天的日期有一圈红框
  - 每格下面还有一行小字：**农历日期**；春节、中秋、清明、国庆这类节日会用朱砂色标出来
- 点任意一天，会弹出那天的目标和备注原话。
- 左上角的 `‹` `›` 翻月份，「本月」一键回到这个月。
- **最多能回看一年**（在「朕的私事 → 历史保留」里可以改成只留 3 个月或半年）。
  改小之后，更早的记录会从这台手机上删掉；中枢上还有一份，但日历也就只能翻到那个范围了。

## 五、自动同步

- 连家里 WiFi、打开 App 时会自动同步到家里那台电脑（电脑上要双击 `tools\start-hub.cmd`，看到一个黑窗口就说明中枢开着）。
- 同步不上也没关系：手机里一直是全的，回家再连一次就会补上。
- 两台设备都改过同一天？按「谁改得晚算谁」，两边的目标都会保留，不会互相覆盖掉。
- 中枢也按同样的一年上限保存，超过一年的旧记录会被自动清掉。

## 六、提醒规则（跟说好的一致）

| 时间 | 什么时候响 | 什么时候不响 |
| --- | --- | --- |
| 07:30 | 当天还没设目标 | 已经设过目标 |
| 21:30 | 当天设过目标，但还有没打卡的 | 当天完全没设目标；或者全都打过卡了 |
| 差事到点 | 传旨里带了钟点的今日差事 / 六部差事，到点响 | 没写钟点；已经办成；钟点已过 |

- 提醒是手机自己发的闹钟，**电脑没开、没网也会响**。
- App 不必开在后台：排好的提醒交给手机系统闹钟；但别在系统里「强行停止」大内家事，
  并给它开自启动 / 省电白名单，否则闹钟会被系统清掉。
- 「朕的私事 → 提醒」里有**通知自检**：权限、精确闹钟、渠道、下一条提醒都列出来；
  还有「补排提醒」「准点闹钟设置」「发测试通知」三个按钮，早上没响先来这里看。
- App 每次打开会把接下来一个月的 07:30 与带钟点的差事排好；如果连续一个月没打开过 App，新差事的提醒就排不上。

## 七、换手机 / 备份

「我的」→「复制全部数据」，复制出来是**一天一行的纯文字**，长这样：

```
2026年11月16日：读书 20 页；跑步 3 公里。
2026年11月17日：背单词；写周报。
2026年11月18日：背单词；跑步 3 公里；早睡。
```

- 日期从早到晚，每条目标用「；」隔开，最后加句号；没有记录的日子不会出现。
- 电脑上看板里也能下载同样的 TXT（点开成员卡片 → 「下载 TXT（每天一行）」），
  或者下载完整 JSON（连打卡状态和备注都在）。
- 数据只存在各自手机和家里电脑上，不经过任何云服务。

## 八、电脑端那个黑窗口

- 双击 `tools\start-hub.cmd` 后应该看到：`Starting family check-in hub ...`，然后几行中文（数据目录、看板地址、局域网地址、网络要求）。
- **第一次运行**会弹一个「是否允许此应用对你的设备进行更改」的管理员窗口——必须点「是」。
  那是给中枢放行防火墙端口（TCP 8787 / UDP 8788），只做一次，以后不再问。
  不放行的话，手机是连不上电脑的（尤其电脑连手机热点时，Windows 会把这网络当「公用」直接拦掉）。
- 看到 `http://127.0.0.1:8787/` 就说明好了，浏览器打开这个地址能看见家里的看板。
  同一行下面还会打印**手机应该填的局域网地址**，比如 `http://192.168.43.106:8787/`。
- 如果提示 `端口 8787 被占用了`：说明已经开着一个中枢窗口了，把旧的关掉再开。
- 如果窗口里出现 `Expand-Archive`、`sdkmanager`、`platform-35` 这类字眼——那不是中枢，
  是装安卓编译环境时的旧窗口。正常使用完全用不到它，关掉即可。

## 九、手机和电脑怎么才算"同一个网络"

下面三种都行，不用改任何设置：

| 接法 | 说明 |
| --- | --- |
| ① 同一个 WiFi | 手机和电脑都连家里路由器 |
| ② 电脑连手机热点 | 电脑连上手机开的热点（电脑会显示 `192.168.43.x` 这类地址） |
| ③ 手机 WiFi + 电脑网线 | 都接同一个路由器，一根网线一个无线也没关系 |

- 中枢每 5 秒会在局域网里"报个到"；手机打开 App、进「我的 → 自动找中枢」时，
  只要两边在同一网络，通常一两秒就能找到。
- 实在找不到就手填：把电脑窗口里那行 `局域网：http://192.168.x.x:8787/` 抄进
  「我的 → 中枢地址 → 保存 → 测试连接」。
- 记得**关掉公司 VPN / 加速器**，它们会把流量拐走，局域网就不通了。

## 十、让 AI 复盘（手机 / 电脑都能点）

- 手机：进「历史」页，最下面那张 **🤖 钦天监推演** 卡片，填一个天数（1–365），点「掐算」，
  等十几秒（最长一分钟），结果直接弹出来。卡片右上角会显示当前用的是哪个模型。
- 电脑：打开看板 `http://127.0.0.1:8787/`，先点一下成员卡片，再点天数按钮，结果显示在该成员下面。
- **同一次数据只会分析一次**：如果这段时间的记录没变，再点同样的天数会直接翻出上次结果，
  **不花 token**（结果标题会标「缓存」）。想重新生成，点结果里的「重新生成」。
- **历史复盘**：卡片下面会列出以前的复盘（手机和电脑都能看），点一条就打开全文；
  每个天数（最近 3 天、最近 7 天…）只列最新 3 条，翻旧的不占地方。
- 复盘由**家里的电脑**调 DeepSeek 生成，内容会同时存到电脑上（`data/analyses/`）。
- 没连中枢时，手机上的按钮是灰的（会写明"还没连上中枢"），不会白转圈。
- 用的是你自己的 DeepSeek key（中枢会自动找：环境变量 → `data/settings.json` → dsh 自己的凭据文件）。
  一次真实生成大概一两千 tokens，**花费不到一分钱**；没配 key 的话，卡片上会直接告诉你缺什么。

## 十一、看板（电脑上那个网页）能看什么

**点谁的卡片，下面就只显示谁的信息**，不会把所有成员堆在一起。

- **成员卡片**：谁今天交了几条、完成多少；名字前面有绿点＝这台手机 2 分钟内连过。
- 点开一位成员后，才看到他的：今天的目标（逐条状态和备注）、这台设备的同步记录（手动/自动）、
  「下载 JSON」「下载 TXT（每天一行）」、AI 复盘按钮和历史复盘。
- **本地备份**：最下面一块显示数据目录，两个按钮可以直接在电脑上打开数据文件夹 / 复盘文件夹。
- 看板每 5 秒自动刷新，不用手动按 F5；正在看的复盘结果不会被刷掉。

## 十二、大内家事（两页：朝廷 / 起居）

底栏分两页：左「🏯 朝廷」、中「📜 起居」，**最右是「朕的私事」**。文案一律古白话。

**第一次用（只做一次）**

1. 最右「朕的私事」→ **我在「大内家事」里的身份**，选「陛下」或「皇后」（其余家人选「家人」）。
2. 同一处可以 **换头像**（点右上角头像也行），换完会传给中枢，电脑看板上也认得出你。
3. 互联中枢：底部「朕的私事 → 自动找中枢」；也可以直接点右上角驿牌。

**朝廷页（进门先看这个）**

| 板块 | 干什么 |
| --- | --- |
| 内阁 | **置顶**；本年度的大计与银钱（计划 + 金额预算）。**不自己添事**：空着只提示「到司礼监传旨」，计划与预算都由传旨定；圆圈里写百分比，点圈弹滑块记进度；条尾「⋯」改措辞 / 预算 / 周期，每桩每年限 **3 次**（光记进度不算）；办成后默认隐藏 |
| 司礼监 | **单独一张卡**：管传旨分派。点「拟旨分发」说一段话，拆成三类差事；传旨只在这里，御书房与内阁都不再放传旨按钮 |
| 御书房 | 六部**一部一行**：名字旁一句短职责（如兵部「管出行安全」），有差事时再显示最近汇总；点进该部：下旨、点圈记进度、撤旨、让该部上奏。不再摆下旨举例 |
| 奏疏 | 七部奏疏都在这里，点开看全文；帝后可朱批 / 留中 / 驳回 / 待合议 |
| 驿牌（右上角） | 就是同步按钮：`驿路未通`→点它找中枢；`待传 N 处`→点它传书；`已同步 19:40`→没事 |

**起居页**

| 板块 | 干什么 |
| --- | --- |
| 今日差事 | **也由司礼监传旨生成**（不再手填）；每条前面一个圈，点圈弹滑块记到几成，100% 算办成、默认隐藏 |
| 行事历 | 月历翻页、点某天看当日差事；每格小字标**农历**，节日（春节 / 中秋 / 清明 / 国庆…）用朱砂色标出，页头也写今日农历 |
| 钦天监推演 | AI 复盘；卡上写清「此为何用」：哪几桩拖住了、哪几天最勤；**直接填推演天数（1–365）**，不用点一排按钮；同数据翻旧卦不花钱 |
| 中枢账房 | 顶栏下一行小字（两页都在）：今日花了多少钱（按 DeepSeek 价目估算）；点开看**每次调用**花了多少、用了多少 tokens、余额多少 |

**司礼监怎么传旨**

1. 入口只有一处：朝廷页「司礼监 · 传旨」卡片里的「拟旨分发」。
2. 把话原样写进去，一段话里可以同时说三类事，例如：
   「今年攒两万去海边旅游；今天背三十个单词、跑步半小时；周六去公园玩，谁去谁留定一下」
3. 司礼监拆成三堆：**内阁大事（带预算）/ 今日差事 / 六部差事**。连上中枢时由模型拆；断网或没配模型时按关键词规矩拆（免费）。
4. 拆完列成清单：可改字、可改预算、可勾选；**每条今日差事 / 六部差事还能定「到点」**（今天下午三点、明早八点、周六上午十点都认得），
   到点手机会响；不点头就只是拟稿。
5. 内阁大事不带到点提醒；只说了日期没说钟点（如「周六去公园」）也不会硬塞闹钟。

**断网也能用**

- 今日差事、内阁大事、六部差事、户部账目，全都先记在这台手机上（中枢只是另一份）。
  回家连上同一 WiFi，App 会把整份国事推给中枢、按时间合并；删掉的留「墓碑」，旧稿再传也不会复活。
- 朝廷页断网照常显示：每部管什么用的是 App 内置的那一份，不靠中枢。
- 头像先换本机，连上中枢再传给看板。
- 要动模型的活（上奏、朝会、推演）断网做不了，按钮会灰着并说明；看过的奏疏会存一份在本机，断网可翻旧奏。
- 账房流水与余额显示上次同步到的数字，不会因为你断网就归零。


**钱的规矩**

- 每次召见六部、传旨、推演，完成后都会弹一句：**本次花了多少、今日共多少、账上还剩多少**。
- 数据没变的重复上奏 / 推演 / 同一段口谕走缓存，记「未耗分文」，不调模型。
- 「中枢账房」里逐笔列着：谁花的、花在哪个部、多少 tokens、**折合多少钱**。
  金额按 DeepSeek 价目估算（闲时半价也算进去了），最终以账户扣费为准。

**说明**

- 六部只出方案，**不会自己改你的目标、预算、分工**——没批就是没生效。
- 每部只读自己领域的数（吏部看打卡、户部看流水…），不会跨部乱说。
- 想让某一部更懂你家，可以在电脑上跑训练场：
  `node tools\court-train.mjs --dept libu --rounds 2`（默认假模型不花钱）。
